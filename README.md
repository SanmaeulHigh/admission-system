# 입학전형관리시스템

고등학교 신입생 입학전형을 **원서 접수부터 합격 발표까지** 한 곳에서 처리하는 웹 시스템입니다.
산마을고등학교가 2027학년도 신입생 전형(2026년 10월 원서 접수 시작)에서 실제로 운영하고 있고,
비슷한 고민을 하는 학교가 가져다 쓸 수 있도록 소스코드를 공개합니다.

> 바로 쓰는 서비스가 아니라 **학교마다 따로 설치해 쓰는 템플릿**입니다.
> 지원자 정보는 설치한 학교의 서버에만 저장되고, 만든 사람이나 다른 학교는 볼 수 없습니다.

## 하는 일

| 단계 | 기능 |
|---|---|
| 원서 접수 | 방문·우편 접수, 접수번호 자동 부여, 접수증 출력·문자·이메일, 우편 도착일 소급, 서류 보관용 L자 화일 표지(QR) |
| 서류 관리 | 스캔 PDF 올리기, 묶음 PDF 나누기, 용량 자동 줄이기, 화면에서 바로 보기, 자기소개서·학부모 소견서 입력본(원본과 번갈아 보기) |
| 채점 | 전형위원별 영역 배정, 서류평가·심층면접·모둠활동·글쓰기 채점, 실시간 진행 현황, 배점·가산점은 설정으로 정하고 점수는 수식으로 계산 |
| 면접 당일 | 수험표 QR 입실 확인, 수기 입실·시각 정정(사유 기록), 면접 호출 문자, 대기실 안내 화면 |
| 사정·발표 | 1단계·2단계 사정, 동점자 처리, 결과 문자, 합격증·응시 확인서 발급, 엑셀 내보내기 |
| 그 밖에 | QR 빠른 조회, 출신 중학교 검색(NEIS), 감사 기록, 교직원 투표, 새 버전 알림, 다크 모드 |

### 역할별 화면

- **최고관리자·관리자**: 전형 설정, 계정·권한, 사정·발표
- **접수 담당**: 원서 입력, 서류 스캔, 접수증·표지 출력 (채점 내용은 보이지 않음)
- **전형위원**: 배정받은 지원자의 서류 읽기와 채점만
- **교장**: 결재용 서류·결과 열람

## 기술 구성

- 화면: React 18 + Vite + Tailwind CSS (PWA)
- 서버: [Supabase](https://supabase.com) — PostgreSQL, 인증, 파일 저장소, Edge Functions(Deno)
  - 학교 PC에 직접 설치(Docker, 셀프 호스팅) 또는 Supabase 클라우드 모두 가능
- 문자: 문자나라 웹연동 / 학교 검색: NEIS 오픈API / 메일: SMTP (모두 선택)

## 보안과 개인정보

- 표를 직접 읽지 못하게 막고(RLS), 모든 읽기·쓰기는 권한을 다시 확인하는 DB 함수로만 합니다.
- 학교 밖에서 접속하면 휴대폰 인증을 한 번 더 받습니다(Cloudflare 터널 구성일 때).
- 입실 시각 정정, 접수일 변경 같은 중요한 수정은 사유와 함께 기록이 남습니다.
- **채점기준표는 저장소에 들어 있지 않습니다.** 각 학교가 DB에 직접 넣습니다(INSTALL.md 6단계).
- 학교 이름은 예시로 `새봄고등학교`(가상)를 넣어 두었습니다. `scripts/set-school-name.mjs`로 바꿉니다.

## 알아 두실 것

- 전형 방법은 학교마다 다릅니다. 배점·일정·모집 인원은 `supabase/setup/`의 예시를 모집요강에 맞게 고쳐 쓰세요.
  예시 값은 한 학교의 2027학년도 요강을 바탕으로 했습니다(인천학생추천전형·사회통합전형 등 지역 전형 포함).
- **사정 결과와 개인정보 처리의 책임은 사용하는 학교에 있습니다.** 실제 전형 전에 모의 데이터로 끝까지 리허설해 보세요.
- 클라우드에 설치하면 지원자 개인정보가 외부(해외 리전 포함) 서버에 저장됩니다. 학교·교육청 개인정보 지침을 먼저 확인하세요.
